- Visual Studio Code sebagai editor kode.
- Google Chrome sebagai web browser.

## 3. Cara Menjalankan Server Lokal

1. Buka aplikasi XAMPP Control Panel.
2. Klik tombol **Start** pada bagian Apache.
3. Pastikan Apache berjalan dengan status aktif.
4. Simpan folder project dengan nama `Lab7Web_PHP` di dalam direktori:

   `C:\xampp\htdocs\`

5. Buka browser Google Chrome.
6. Masukkan alamat berikut:

   `http://localhost/Lab7Web_PHP/`

7. Untuk menjalankan file tertentu, tambahkan nama file pada URL. Contoh:

   `http://localhost/Lab7Web_PHP/index.php`
